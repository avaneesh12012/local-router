Local Router Documentation

Local Router is a zero-configuration, browser-based chat client designed for the OpenRouter API. It removes the need for backend infrastructure by managing API keys and history locally via localStorage.

Includes native support for Markdown, LaTeX, and Syntax Highlighting. Features tools to track usage costs and supports vision models.
