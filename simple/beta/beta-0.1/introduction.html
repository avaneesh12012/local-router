Local Router

Local Router was created to simplify the experience for users who want to avoid the complexity of editing configuration or .env files across different setup environments.

About the Project

Local Router provides a pre-configured UI environment for API keys, offering a faster alternative to other apps where setup can be time-consuming or prone to breaking. Our goal is to support full Markdown and HTML previews to make the application entirely self-sufficient.

Currently, in version 0.1, the project is transitioning from a hobby to a professional ambition. We aim to reach a "next-level" stable release within the next 3-4 months. Please note that some LaTeX issues exist in v0.1; refer to the LaTeX Issues page for solutions.

Single HTML File

The single HTML file contains all necessary CSS and JavaScript code, wrapped in a minimal UI structure. For version 0.1, the UI was kept intentionally simple so development could focus on core features rather than polished aesthetics with broken functionality.

The UI was designed with the assistance of AI tools to ensure rapid development. As the AI industry grows, we believe leveraging these tools is essential for modern project efficiency. While the standalone HTML file will remain lightweight and fast, the UI will continue to modernize so it never feels "cheap" or outdated. Your chats are stored locally in your browser's localStorage and are never uploaded to external servers.

Website

The link will be provided here and in the README.md once the site is deployed.

The web version will be more interactive and polished for beginners. It will feature optional sign-up for safety. You may choose to store your API keys in our encrypted cloud, though we recommend local storage as we do not take liability for key leaks or service disruptions. Our ambition is to keep the project free and open-source, without advertisements or subscriptions.

Applications

Note: iOS and macOS applications are not currently planned. Please use the web or HTML version on those platforms.

Android

We plan to release a dedicated Android application so users do not need to rely on a browser. Due to financial constraints, the app will not be on the Play Store but will be available as a .apk download on GitHub and our website.
Warning: Never install Local Router from third-party stores like Softonic, as they may inject malware. Only use the official links provided here.

Windows

A Windows desktop application is planned following the Android release. You will be able to download the installer or the full source code to build it yourself. As with the mobile version, only trust installers downloaded from our official documentation or GitHub repository.
